I've identified and fixed the cause of the "Minified React error #185," which indicates an infinite re-render loop.

The issue was located in the ChapterEditorView component. A circular data flow was occurring:

User input was saved to the component's local state (e.g., content).

A debounced useEffect hook updated the global Zustand store with this local state.

This store update caused the component to re-render.

Another useEffect hook was watching for any change to the chapter object from the store and would reset the component's local state from the store's data.

This cycle (local state -> global store -> component re-render -> local state reset) created a continuous loop, causing the application to crash.

To fix this, I've adjusted the dependency array of the useEffect hook that syncs the store's data to the component. Instead of watching the entire chapter object reference, it now only re-runs if the chapterId or the primitive values of the chapter's title, content, or notes change. This breaks the loop by preventing the editor from resetting its own state after it has just saved it, while still allowing it to update correctly if the user switches to a different chapter.
